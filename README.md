# xv6 RISC-V : CS744 Lab 3

This repository contains a modified version of **xv6**, a teaching operating
system originally developed at MIT. xv6 is a re-implementation of Dennis
Ritchie's and Ken Thompson's Unix Version 6 (V6), adapted for modern RISC-V
multiprocessor systems and implemented in ANSI C.

This version has been extended and modified as part of **CS744 Lab 3**.
The purpose of the project is to understand the design and implementation of
operating-system components by adding new kernel functionality to xv6.

## About xv6

xv6 loosely follows the structure and style of Unix V6 while providing a
simplified and understandable codebase suitable for operating-systems
education.

The original xv6 project is maintained by MIT and is used in operating
systems courses including MIT's 6.1810.

## CS744 Lab 3 Modifications

The following changes and extensions have been implemented as part of this
lab:

- Added new system functionality to xv6.
- Modified the kernel to support the requirements specified in CS744 Lab 3.
- Added or modified system calls where required.
- Updated kernel data structures and supporting code.
- Added user-level programs/tests for the new functionality.
- Modified the build system and source files where necessary.
- Added synchronization and/or process-management support where required.
- Tested the modified kernel using QEMU and xv6 user programs.
